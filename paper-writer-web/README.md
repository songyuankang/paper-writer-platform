# paper-writer-web

论文生成助手前端（React + TypeScript + Vite + Tailwind CSS）。

只负责调用 [paper-writer-api](../paper-writer-api) 的接口，不包含任何论文生成逻辑；
不修改 paper-writer Skill；配套的 paper-writer-api 接口层随本项目一起演进。

## 功能

- **首页落地页 `/`**：论文类型入口（毕业论文（本科）/课程论文/开题报告/文献综述/段落优化），导航栏直达各功能
- **四步创作向导 `/create`**：仿 aiunipaper 的创作流程 ① 论文选题 → ② 生成摘要 → ③ 参考文献 → ④ 论文正文；12 大学科门类 + 专业类选择、推荐选题、字数/语种/其他要求，生成过程分步展示实时进度
- **资料上传**：向导第 ① 步支持上传参考资料（开题报告/仿写论文/其他资料），最多 5 个文件、每个 ≤5MB（txt/docx/xls/xlsx/jpg/jpeg/png），并附写作倾向/大纲要求文本框；后端提取文档文本供 AI 参考
- **段落优化 `/polish`**：独立于论文任务，对粘贴文本进行 润色/扩写/缩写/修改/翻译（调用 `POST /api/polish`）
- **逐段生成编辑器（第④步正文）**：仿 aiunipaper /mainbody——左大纲树（三级）+ 右编辑区；每个末级小节可"生成段落"（按主旨），段落可新增/上移/下移/删除/编辑；标题与段落主旨可改；支持一键全文（后台逐节生成）、导出全文（docx）、生成致谢、生成英文摘要
- 经典生成页 `/generate`：三种论文生成方式（自动生成论文/根据我的大纲生成/AI 生成大纲后确认）、图表设置、学校模板、参考文献格式（GB/T 7714 / APA / MLA）
- 高级设置：特殊要求（可选）——可填写“增加案例分析 / 强化某章节 / 调整写作风格 / 增加数据分析”等额外要求，不填写不影响生成
- 图表设置：开启/关闭图表；开启后可多选 20 种图表类型（比较/趋势/分布/构成/流程五类），每种类型可单独设置生成张数（每类 1–20，总数量上限 20），按专业智能推荐；总体生成数量只读显示（由各类型数量合计，不可直接修改）
- 大纲编辑器：多行大纲输入、章节预览、一级章节上移/下移（自动重排编号）、保存/恢复大纲（localStorage）
- 学校模板上传：`.docx`，显示文件名、大小、状态，客户端校验扩展名与 20 MB 上限
- 模板记忆：上传的模板自动保存到浏览器本地（IndexedDB），刷新后仍在；支持重命名、删除、一键复用，并自动记住上次使用的模板
- 提交后自动轮询 `GET /api/status/{task_id}`（或 SSE 流），展示实时进度与阶段文案
- 论文预览页 `/preview/{task_id}`：在线查看正文（目录导航、图表缩略图点击放大、普通阅读/论文排版两种模式、检查报告），无需先下载 docx
- 论文修改：预览页可对章节（重新生成/扩展/精简/自定义）、段落（AI润色/扩写/改写/删除）直接修改，支持全文分析（问题+建议）与版本管理（查看/恢复），修改保存为新版本不覆盖原文件
- 历史记录页 `/history`：生成记录卡片（标题/专业/字数/状态/时间），支持按标题搜索、按状态筛选、预览、下载、删除、一键重新生成（复用上次参数）
- 完成后提供下载：论文.docx、格式意见.md、图表文件、全部打包 ZIP
- 响应式中文界面，手机/电脑自适应

## 安装

```bash
npm install
```

## 启动

```bash
npm run dev
```

浏览器打开 http://localhost:5173 。

> 开发服务器已配置监听所有网卡，`http://localhost:5173`、`http://127.0.0.1:5173`
> 以及局域网 IP 均可访问；端口被占用时 `npm run dev` 会直接报错（strictPort），
> 请先释放 5173 端口。

生产构建：

```bash
npm run build     # 产物输出到 dist/
npm run preview   # 本地预览构建产物
```

## 常见问题：打开是空白

1. 请确认是通过 `npm run dev` 后访问 **http://localhost:5173**（或 127.0.0.1:5173），
   而不是直接双击打开 `dist/index.html` —— `file://` 协议下浏览器会禁止加载 ES 模块，
   页面会空白；生产构建请用 `npm run preview` 或部署到静态服务器后再访问
2. 页面出错时现在会显示“页面出错了”和具体错误信息（而不是空白），按提示排查或刷新重试
3. 如果浏览器显示“无法连接”，说明 dev server 未启动或 5173 端口被占用，查看终端日志
4. 强缓存问题可尝试 Ctrl+F5 强制刷新

## 学校模板的本地记忆

- 上传模板后，文件会保存到当前浏览器的 IndexedDB（`paper-writer-templates`），不经过后端存储
- 刷新或重新打开页面后，模板列表仍会显示；上次使用的模板会自动选中
- 每个模板可重命名（不含扩展名）、删除；删除前有确认提示
- 生成论文时会把选中的模板作为 `school_template` 文件提交给 paper-writer-api，后端校验逻辑不变
- 说明：模板只保存在当前浏览器（清除浏览器数据会丢失）；如需多设备共享模板库，可后续在 paper-writer-api 增加模板库接口

## 三种生成方式

### 自动生成论文（默认）

保持原有表单与流程：提交 `POST /api/generate`（不传 `generation_mode`，后端默认 `auto`），
按论文类型自动规划结构并生成。

### 根据我的大纲生成

1. 生成方式选择“根据我的大纲生成”
2. 在大纲编辑器中粘贴章节文本，例如：

   ```text
   第一章 绪论
   1.1 研究背景
   1.2 研究意义

   第二章 相关理论
   2.1 理论基础
   2.2 文献回顾
   ```

3. 可用“上移/下移”调整一级章节顺序（自动重排编号），可“保存大纲”到本机
4. 点击“按大纲生成论文”，提交参数 `generation_mode=outline` + `outline=大纲文本`

### AI 生成大纲后确认

1. 生成方式选择“AI 生成大纲后确认”
2. 填写标题、专业、字数，点击“生成大纲”，调用 `POST /api/outline/generate`
3. 页面展示大纲预览：章节结构 + 预计字数分配（可继续在编辑器中修改）
4. 点击“确认大纲并生成论文”，以 `generation_mode=outline` + 确认后的大纲提交

## 图表设置

1. “图表生成”选择“开启”，展开图表设置面板
2. 点击“按专业智能推荐”可自动勾选本专业常用图表类型（计算机：流程图/折线图/柱状图；教育学：柱状图/饼图/雷达图；经管：折线图/热力图/桑基图等），也可自行勾选
3. 每种已勾选图表类型后面有 “− 数量 +” 步进器，可单独设置该类型的生成张数（1–20，总张数上限 20）；“总体生成数量”只读显示各类型数量之和，不可直接修改
4. 提交时携带 `chart_config`：`types` 按各类型数量重复展开、`count` 为总张数，例如 柱状图×2 + 折线图×1 → `{"enabled":true,"count":3,"types":["bar","bar","line"]}`；后端生成 `figure_1.png…figure_N.png` 并插入论文，图号自动编号（图1-1、图1-2、图2-1…），正文自动引用“如图1-1所示”
5. 下载产物包含 `charts/`（PNG + `chart_data.json`）

例如选择“折线图×1 + 柱状图×2”，总体数量显示 3，将生成 3 张图（折线图、柱状图、柱状图）。

> 兼容性：不提交 `chart_config` 时仍走旧逻辑（`chart_enabled` 生成 1 张示例图表）。

## 论文预览

生成完成后点击“在线查看论文”进入 `/preview/{task_id}`：

- 左侧目录：摘要、关键词、各章节、参考文献，点击平滑跳转到正文对应位置
- 右侧正文：标题、摘要、段落、表格、图表（点击放大并显示图号/标题）、参考文献
- 右上角切换“普通阅读 / 论文排版”两种模式：排版模式使用宋体、页边距、标题层级与
  图表居中布局，尽量接近最终 Word 效果
- 顶部检查报告：字数（含目标字数）、图表数、参考文献数、格式检查（通过/需处理）
- “编辑（预留）”按钮暂为只读占位，后续开放修改/重新生成章节
- “下载 docx”与“打印 / 导出 PDF”（浏览器打印对话框可另存为 PDF）不占用下载接口

生产部署时静态服务器需把未知路径回退到 `index.html`（如 Nginx `try_files $uri /index.html;`），
否则刷新 `/preview/xxx` 会 404。

## 历史记录

生成完成后记录自动保存到后端（SQLite）；在结果区点击“在线查看论文”进入预览页。

- 点击页面右上角“历史记录”（或直接访问 `/history`）
- 卡片显示标题、专业、字数、类型、状态（✓ 已完成 / ✕ 失败 / ⏳ 生成中）、时间
- 搜索框按标题过滤；状态下拉筛选“全部 / 生成中 / 已完成 / 失败”；按时间倒序
- 按钮：预览（进入 `/preview/{task_id}`）、下载（论文.docx）、重新生成（读取上次参数提交新任务，完成后自动进入新预览页）、删除（确认后同时删除数据库记录与生成文件/图表/上传模板）
- 说明：重新生成会复用上次的标题/专业/字数/图表/参考文献/大纲等参数；学校模板需在生成页重新上传

## 高级设置（特殊要求）

- 表单底部“高级设置”展开后为“特殊要求”输入框（非必填，可留空）
- 支持填写任意额外要求，例如：增加案例分析、强化某章节、调整写作风格、增加数据分析
- 提交后该内容会应用到生成内容（摘要与各章节段落会体现特殊要求），并在预览页“特殊要求”栏显示；未填写时显示“无”
- 特殊要求为空不会阻止提交，也不影响默认生成流程

## 论文修改

预览页中：

- 章节标题下操作：重新生成本章、扩展本章、精简本章、自定义修改（弹窗填写修改要求）
- 鼠标悬停段落：AI润色、扩写、改写、删除
- 顶部“分析问题 / 生成修改建议”：调用全文分析，展示问题列表与修改建议
- “修改记录”区：版本 1 初始论文、版本 2 修改第三章……支持“恢复此版本”
- 每次修改保存为新版本并重建 `paper_vN.docx`（下载 docx 仍为原始 论文.docx；如需修改版可经版本记录/预览查看）
- 说明：当前修改为规则化示例实现（内容标注【修改示例】），正式版将接入 LLM 生成

## DeepSeek 内容生成

- 后端配置 `DEEPSEEK_API_KEY`（与 `DEEPSEEK_MODEL`）后，论文内容由 DeepSeek 生成，
  前端无需任何改动；未配置时后端自动回退示例占位内容
- 生成过程中进度条会显示阶段文案：正在生成摘要…、正在生成第一章：xxx…等
  （来自状态接口 `message` 字段）
- 进度推送：前端通过 SSE（`GET /api/generate/stream/{task_id}`）实时接收
  “正在生成论文规划 / 摘要 / 第X章 / 结论 / 参考文献 / 检查论文”等阶段；SSE 异常时自动回退轮询
- 后端默认使用分段生成（`generation_strategy=section`）：逐章独立调用大模型，支持断点续传，
  每章只携带大纲与前章摘要以减少 token 消耗；`single` 为一次生成（测试用）

## AI 模型配置中心

- 页面：设置 → AI 模型配置（`/settings/models`），支持新增/编辑/删除、启用/禁用、测试连接、设为默认
- 表单字段：模型名称、Provider、API Base URL、API Key（密码框，支持显示/隐藏/复制）、Model、是否默认
- API Key 仅创建时显示一次，之后接口只返回掩码（如 `******abc123`），数据库加密保存
- 生成页新增“AI 模型”下拉：默认使用当前默认模型，也可手动切换到任意已启用模型
- 支持任意 OpenAI 兼容接口，例如：DeepSeek `https://api.deepseek.com/v1`、
  OpenAI `https://api.openai.com/v1`、本地 Ollama `http://localhost:11434/v1`、
  OpenRouter `https://openrouter.ai/api/v1`

## 内容生成与格式处理分离

- 架构：后端 `generation/`（第一阶段，只生成论文内容）与 `formatter/`（第二阶段，
  markdown/json → docx）完全分离；格式处理逻辑未改动
- 生成完成后页面显示“论文内容预览”（摘要/章节/结论，纯内容，非 Word 文件），
  以及“下一步：进入格式处理”按钮（调用 `POST /api/format/{task_id}` 生成 docx 后即可下载）
- 任务状态显示规划/大纲/逐章/结论/检查等阶段；断点续传（某章失败自动从该章继续）

## 格式处理页面（/format/:task_id）

- 内容生成完成后，内容预览面板点击“下一步：进入格式处理”跳转到 `/format/{task_id}`
- 页面模块：
  1. 学校模板选择：当前模板（默认/学校模板），上传 .docx 自动解析并保存 template_id，
     显示学校/专业/论文类型/更新时间
  2. 格式设置：是否使用学校模板（关闭则默认格式）
  3. 目录设置：自动生成目录 / 更新页码 / 更新标题编号
  4. 参考文献设置：GB/T 7714 / APA / MLA + 自动排序 / 自动编号
  5. 图表设置：图表编号（图1-1）与位置自动调整
  6. 开始格式处理 → 后台 FormatTask（waiting→processing→checking→completed），
     完成后下载 论文.docx / FormatReport.md / 全部 ZIP
- 格式功能不再出现在论文生成页（生成页只负责内容）

## 环境变量说明

复制 `.env.example` 为 `.env`：

```bash
# paper-writer-api 服务地址
VITE_API_URL=http://localhost:8000
```

- **留空（默认）**：开发模式下由 Vite 代理把 `/api` 转发到后端（默认 `http://localhost:8000`，可用 `VITE_API_URL` 指定代理目标），前端无需处理跨域
- **填写完整地址**：`fetch` 将直接请求该地址；若前后端不同源，需要后端配置 CORS，或由 nginx 等反向代理保证同源

修改环境变量后需重启 `npm run dev`。

## 如何连接 API

1. 先启动后端：

   ```bash
   cd ../paper-writer-api
   pip install -r requirements.txt
   uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```

2. 前端保持 `.env` 中 `VITE_API_URL` 留空（走代理）或指向后端地址
3. 打开 http://localhost:5173 提交表单即可；页面会依次调用
   `POST /api/generate` → `GET /api/status/{task_id}` → `GET /api/download/{task_id}?file=...`

## 说明

- 论文类型下拉中的“开题报告”“调研报告”当前映射为“课程论文”提交（后端暂未支持独立类型），见页面提示
- 下载链接经 `/api/download/{task_id}` 提供，文件名为中文时会自动 URL 编码
- 后端第一阶段输出为示例占位内容，接入真实内容生成后前端无需改动

## 下一步部署方案

- **静态托管**：`npm run build` 生成 `dist/`，部署到 Nginx / Vercel / Netlify / 对象存储等任意静态服务器
- **同源反代（推荐）**：Nginx 将 `/` 指向前端 `dist/`，将 `/api/` 反向代理到 paper-writer-api（8000 端口），浏览器无跨域问题
- **容器化**：前端构建后用 Nginx 镜像托管静态文件；API 按 paper-writer-api 的 Dockerfile 部署，两个容器通过内部网络或反代互通
